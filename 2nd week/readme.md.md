## Tasks

### 1. Advanced Hyperparameter Optimization

Compared different strategies for tuning model hyperparameters and evaluated their impact on performance.

- Explained the difference between parameters and hyperparameters
- Covered Grid Search, Random Search, Bayesian Optimization, and Genetic Algorithms
- Compared the four approaches on search efficiency and resulting model performance

### 2. Bias-Variance Tradeoff

Studied how model complexity affects underfitting, overfitting, and generalization.

- Explained underfitting and overfitting with examples
- Broke down the bias-variance tradeoff and its effect on model accuracy
- Used cross-validation to evaluate generalization performance

### 3. Boosting Algorithms

Built and compared boosting-based ensemble models on a gaming player churn dataset.

- Implemented AdaBoost and Gradient Boosting from the ground up
- Introduced XGBoost as an optimized boosting framework
- Trained models to predict player churn and compared their accuracy

### 4. Data Validation

Cleaned and validated a finance dataset, then examined how data quality issues connect to model overfitting.

- Detected and handled missing values and duplicate records
- Identified outliers and applied data cleaning techniques
- Defined validation rules to ensure data quality before modeling
- Analyzed how unclean or unvalidated data contributes to overfitting

### 5. KNN & Decision Tree Hyperparameter Tuning

Tuned two more classification models and compared how hyperparameter choices affect their performance.

- Trained K-Nearest Neighbors (KNN) and Decision Tree classifiers
- Tuned key hyperparameters (e.g., k value, tree depth, split criteria)
- Evaluated and compared both models' performance after tuning

### 6. Random Forest & SVM Hyperparameter Tuning

Tuned two classification models and evaluated the effect of hyperparameter choices on results.

- Trained Random Forest and Support Vector Machine (SVM) classifiers
- Used GridSearchCV to search for optimal hyperparameters
- Evaluated and compared both models' performance after tuning

### 7. Unsupervised Learning

Applied clustering and association rule mining to uncover patterns without labeled data.

- Implemented K-Means and Hierarchical Clustering to group similar data points
- Applied the Apriori algorithm for association rule mining
- Extracted and interpreted frequent patterns and item relationships
