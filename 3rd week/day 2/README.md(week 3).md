## 📓 Notebook — `Trainingg_ANN_Notebook.ipynb`

An end-to-end walkthrough of how neural networks learn, organized into a
Table of Contents with clickable section links.

### Topics covered

1. **Learning Process in ANN** — prediction → error → cost → weight update cycle
2. **Loss Functions** — MAE, MSE, Huber, Binary Cross-Entropy, Categorical Cross-Entropy
   - *Task 1*: Implement loss functions from scratch with NumPy (cross-checked against scikit-learn)
   - *Task 2*: Visualize regression and classification losses
3. **Gradient Descent** — Batch, Stochastic, Mini-Batch variants
   - *Task 3*: Implement gradient descent on a simple linear regression problem
4. **Backpropagation** — chain rule and gradient computation
5. **Optimizers** — SGD, Momentum, RMSProp, Adam (comparison table)
   - *Task 4*: Train an ANN with TensorFlow/Keras on the Breast Cancer dataset, comparing SGD vs. Adam
6. **Hyperparameter Effects** — learning rate, batch size, epochs
   - *Task 5*: Hyperparameter experiments with results logged to a comparison table (CSV)
7. **Evaluation Visualizations**
   - *Task 6*: Loss/accuracy curves, confusion matrix, ROC curve, precision–recall curve
8. **Discussion & Experimental Results**
9. **Research Task** — summary and synthesis of three published papers comparing optimizers
10. **Conclusion & References**

### Requirements

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow
```

### How to run

Open the notebook in Jupyter or VS Code and run the cells top to bottom:

```bash
jupyter notebook Trainingg_ANN_Notebook.ipynb
```

Plots and CSV comparison tables generated by the tasks are saved to an
`outputs/` folder created alongside the notebook.

> **Dataset used:** scikit-learn's built-in **Breast Cancer Wisconsin** dataset
> (loaded via `sklearn.datasets.load_breast_cancer`) — no external download needed.

## 🖥️ Presentation — `Training_ANN_HowNetworksLearn.pptx`

A 21-slide lecture deck that mirrors the notebook's structure, intended for
in-class delivery.

### Slide flow

- **Title & Session Overview** — 8 learning outcomes for the session
- **Quick Review** — ANN architecture recap (layers, weights, activations, forward propagation)
- **How Networks Learn** — the prediction → error → cost → update cycle, with a flowchart
- **Loss Functions** — regression losses, classification losses, and a task-to-loss comparison table
- **Gradient Descent** — the core idea, cost surface, and Batch/SGD/Mini-Batch variants with a convergence chart
- **Backpropagation** — error propagation and a computational-graph walkthrough
- **Optimizers** — SGD, Momentum, RMSProp, Adam/AdamW comparison
- **Evaluating Training** — learning curves, accuracy curves, early stopping
- **Common Problems** — vanishing/exploding gradients, poor initialization, dead ReLU — with solutions
- **Best Practices** — LR scheduling, batch size selection, epoch selection, checkpointing
- **Summary & Thank You**

### How to use

Open directly in PowerPoint, Keynote, or Google Slides — no additional
software required.

## 🎯 Learning Outcomes

By the end of this material, learners will be able to:

- Explain how neural networks learn from data
- Compare different loss functions and when to use each
- Implement and reason about gradient descent variants
- Understand backpropagation via the chain rule
- Compare optimizers (SGD, Momentum, RMSProp, Adam)
- Read and diagnose learning curves for overfitting/underfitting
- Build and train an ANN using TensorFlow/Keras
- Recognize and fix common training problems (vanishing/exploding gradients, dead ReLU, poor initialization)
